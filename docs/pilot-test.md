# Пилотная проверка Flametree Analytics MCP

Инструкция для участников пробы. Нужны: учётная запись портала Flametree на стенде пробы
(test или dev) и учётная запись Claude: для чата подойдёт любой план, для Claude Code нужен платный. Вход в GitLab и GitHub не
нужен, репозитории публичные. Весь путь занимает около 10 минут.

## 1. Установка и вход

Подойдёт чат Claude или Claude Code, порядок в [инструкции пользователя](user-guide.md). Стенд для пробы: test (плагин `flametree-analytics-test`) или dev (`flametree-analytics-dev`).

Чат Claude: Customize → Plugins → Add → Add marketplace → Add from a repository → `https://github.com/NewAndry/flametree-superset-agent-skills` → Sync → Add у плагина своего стенда → Connectors → Connect → Continue → Add → Connect → вход в портал.

Claude Code: вставьте фразу, выберите стенд, когда Claude спросит, и следуйте его подсказкам:

```text
Install the Flametree Analytics MCP plugin from https://gitlab.enfint.ai/flametree/flametree-superset-agent-skills
```

## 2. Включить плагин

Чат: начните новый чат, проверьте, что коннектор плагина включён. Claude Code: после установки откройте новую сессию, в ней само откроется окно входа. После первого входа откройте ещё одну новую сессию, в ней инструменты уже на месте.

## 3. Проверки

Выполняйте по порядку, каждую в том же чате. Рядом указано, что должно получиться.

| # | Что сказать Claude | Ожидаемо |
|---|---|---|
| 1 | `Покажи мои тенанты в Flametree и какой активен` | Список ваших компаний и активная. Если компания одна, Claude сразу работает с ней. Если несколько, Claude спросит, с какой работать |
| 2 | `Сколько всего сессий и сколько в среднем сообщений на сессию?` | Две цифры по активной компании |
| 3 | `Собери дашборд «Обзор агента» за всё время` | Восемь чартов, дашборд в фирменном стиле (фильтры сверху, вкладки Fast Facts и Trends), ссылка и вопрос «Опубликовать в портал?». Без вашего «да» публикации быть не должно |
| 4 | Откройте ссылку из п. 3, нажмите **Login with Flametree**, войдите как в портал | Дашборд открылся в Superset под вашей учётной записью, цифры совпадают с п. 2 |
| 5 | `Да, опубликуй в портал` | Ссылка вида `…/custom/<id>`. По ней дашборд открывается в портале в разделе Custom dashboards |
| 6 | `Убери этот дашборд из портала` | Запись в портале исчезла, дашборд в Superset остался |
| 7 | `Выполни SQL: select count(*) from datamarts.hp_sessions` | Отказ: SQL для этой роли закрыт. Claude предлагает построить чарт |

Дополнительно, если у вас несколько компаний:

| # | Что сказать | Ожидаемо |
|---|---|---|
| 8 | `Переключись на <другая компания> и повтори цифры` | Цифры изменились |
| 9 | `Переключись на <компания, к которой у вас нет доступа>` | Отказ «Tenant … is not available» |

## 4. Что прислать по итогам

Ответьте одним сообщением:

1. Номера проверок, которые прошли, и которые нет.
2. Для непрошедших: точный текст ответа Claude или ошибки, скриншот приветствуется.
3. Сколько времени заняла установка и вход.
4. Что было непонятно или неудобно.

Логины, пароли и токены присылать не нужно, они нигде не выводятся.

## Известные ограничения пробы

- Данные dev-контура тестовые. Чарт «Среднее время ответа бота» пока пустой для личных
  учётных записей, это известная проблема, чинится.
- Токен входа живёт около суток, потом Claude попросит войти заново.
- Первый вызов каждого изменяющего инструмента Claude подтверждает у вас. Можно нажать
  **Always allow**, кроме публикации в портал: её лучше подтверждать каждый раз.
- Названия чужих чартов в общих датасетах видны, данные по ним закрыты.
